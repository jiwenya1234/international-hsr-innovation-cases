# 正式公开前检查表

## 样本

- [ ] JSON中恰好有64个案例；
- [ ] 编号唯一且固定为`HSR-001`至`HSR-064`；
- [ ] 每个项目只计数一次；
- [ ] 所有案例均已人工确认进入论文样本；
- [ ] 不包含候选、待补证、排除或重复记录。

## 案例内容

- [ ] 中英文名称与论文、附录和数据表一致；
- [ ] 国家、年份、参与主体和合作形式已核验；
- [ ] 合作过程、知识流动和创新结果有来源支持；
- [ ] 每例均填写纳入理由和证据等级；
- [ ] 不把自动生成草稿当作已核验事实。

## 来源与权限

- [ ] 每例至少有一个可访问的可靠来源；
- [ ] 来源包含标题、机构、网址和访问日期；
- [ ] 已检查失效链接；
- [ ] 未上传网页全文、付费PDF或大段版权文本；
- [ ] 未上传个人信息、密钥、本地路径和内部笔记。

## 发布

- [ ] 版本改为`1.0.0`并填写发布日期；
- [ ] `npm run prepare`检查通过；
- [ ] CSV与JSON数量、编号和内容一致；
- [ ] 主页显示“64 / 64”；
- [ ] 桌面和手机页面均可正常检索与打开证据链接；
- [ ] `CITATION.cff`中的作者、标题和日期准确。
