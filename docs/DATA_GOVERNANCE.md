# 数据公开与治理说明

## 1. 公开目标

本仓库公开到能够核查“案例是什么、为什么纳入、合作如何发生、证据在哪里”的程度，不公开能够复制全部研究档案的原始资料。

## 2. 公开内容

- 64个正式案例的编号、名称、国家和年份；
- 机构层面的参与主体及项目角色；
- 合作形式、技术领域和研究者概括；
- 合作创新过程、知识流动和创新结果；
- 纳入依据、证据等级和原始来源索引；
- 检索、筛选、归并和核验方法；
- 公开数据版本、更新时间和引用方式。

## 3. 不公开内容

- 批量抓取的网页全文、付费内容和受版权保护的PDF；
- 研究者私人笔记、导师意见和内部讨论；
- 未核验的自动摘要、104个候选项目及被排除项目；
- API密钥、账号信息、本地路径和运行日志；
- 内部编码推理、尚未发表的模型结果和fsQCA校准资料；
- 任何个人联系方式或无关个人信息。

## 4. 来源与版权

公开页面保存来源标题、发布机构、网址、访问日期和证据用途。案例文字应以研究者概括为主，避免大段复制第三方原文。第三方内容的版权和再利用许可仍由原发布者决定。

## 5. 版本管理

- 预览版使用`0.x.x-preview`，不得宣称已经形成64例正式数据集。
- 首个64例正式版本使用`1.0.0`。
- 事实修正提高补丁版本，如`1.0.1`。
- 增加字段或改变编码规则提高次版本，如`1.1.0`。
- 每次正式发布记录日期、修改内容和受影响案例编号。

## 6. 仓库隔离

本公开仓库与本地研究管理系统相互独立。公开仓库中的每个文件均应视为任何人都可以查看和下载，不通过隐藏文件夹保存保密资料。
